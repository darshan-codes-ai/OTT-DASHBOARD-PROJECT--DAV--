# OTT Streaming Platforms Content Analytics

## Project Overview

**Project Title:** OTT Streaming Platforms Content Analytics

**Project Type:** Data Analytics & Visualization Course Project

**Platforms Analyzed:**
- Netflix
- Hulu
- Prime Video
- Disney+

**Primary Dataset:** `MoviesOnStreamingPlatforms.csv`

## Project Objective

The purpose of this project is to analyze OTT streaming-platform data and transform it into meaningful visual insights.

The project focuses on understanding how streaming platforms differ in:
- Content availability
- Genre distribution
- Ratings and content quality
- Overall platform characteristics

The central analytical question is:

> How does content availability, genre mix, and audience/critic ratings differ across streaming platforms?

## Dataset

The project uses the `MoviesOnStreamingPlatforms.csv` dataset.

The presentation should use only dataset fields and values that are actually available in the source materials.

Relevant information may include platform, movie/content information, genre or classification, ratings, and other metadata contained in the dataset.

**Important:** Do not invent dataset columns, statistics, percentages, averages, rankings, or findings.

## Main Analytical Areas

### 1. Platform Analysis

Compare:
- Netflix
- Hulu
- Prime Video
- Disney+

The analysis should examine content availability and other platform-level metrics supported by the dataset.

A suitable visualization is a platform-wise comparison chart, such as a horizontal bar chart when actual counts are available.

### 2. Genre Analysis

Analyze how genres are distributed across the four platforms.

Useful visualizations include:
- Platform × Genre heatmap
- Grouped bar chart
- Stacked bar chart

The visualization should make differences in genre distribution easy to understand.

### 3. Rating Analysis

Analyze the rating information available in the dataset.

Where supported by the data, this may include:
- IMDb ratings
- Rotten Tomatoes scores
- Rating distributions
- Platform-wise rating comparisons

Do not claim that one platform has better content unless the actual data supports that conclusion.

### 4. Cross-Platform Comparison

Compare Netflix, Hulu, Prime Video, and Disney+ using relevant metrics supported by the project.

The goal is to identify meaningful differences and patterns rather than simply listing platform descriptions.
