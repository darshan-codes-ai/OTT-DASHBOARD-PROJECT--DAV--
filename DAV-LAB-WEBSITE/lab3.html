Laboratories / Assignment 03

Statistical Visualizations with Seaborn

Advanced statistical distributions, boxplot quartile spreads, histogram density curves, and a 6×6 Pearson correlation matrix preserving the original 0–100 score scale.

Notebook: DAV_Lab_Assignment_3_Movie_Streaming_Analysis.ipynb
Primary Libraries: Seaborn, Matplotlib, SciPy, Pandas
Active Score Scale: Scale: 0–100 (Notebook Raw)

Laboratory 3 extends basic descriptive charts into formal statistical visualization. Using Python's Seaborn statistical data visualization library, the analysis tests parametric normality assumptions, compares rating spreads across demographic tiers, and inspects inter-platform correlation patterns.

Academic Provenance: Preserving the Native 0–100 Rotten Tomatoes Scale

Unlike Lab 1 and Lab 2 which normalized scores to a 0–10 scale, the original Lab 3 notebook analyzes Rotten Tomatoes ratings on the original 0–100 scale. All statistical estimators across the 9,508 scored movies adhere strictly to this native scale:

Steps 1 & 4

Score Distributions by Age Rating (Boxplot & Violin Plot)

0–100 Scale

To evaluate how ratings differ across audiences, missing age values are filtered out, yielding 5,338 records across the ordered ratings: all, 7+, 13+, 16+, and 18+.

Seaborn Boxplot Implementation (Step 1) 
# Step 1.1: Remove missing Age values
plot_df = df[df['Age'].notna() & df['Rotten Tomatoes Score'].notna()]
age_order = ['all', '7+', '13+', '16+', '18+']

# Step 1.2: Boxplot by Age
plt.figure(figsize=(8, 5))
sns.boxplot(data=plot_df, x='Age', y='Rotten Tomatoes Score', order=age_order)
plt.title("Rotten Tomatoes Score by Age Rating")
plt.show()
