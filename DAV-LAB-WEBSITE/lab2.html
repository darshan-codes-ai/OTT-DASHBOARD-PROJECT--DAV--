Laboratories / Assignment 02

Excel Formula-Based Analytics Dashboard

Spreadsheet architecture, formula verification (COUNTIF, MINIFS, AVERAGEIFS), and an in-depth audit of the 9 analytical dashboard modules.

Workbook: DAV_Lab_Assignment_2_Movie_Streaming_Platform.xlsx
Sheets: DATA (9,516 rows) & DASHBOARD
Audited Sections: 9 Modules Verified

Laboratory 2 translates the streaming analysis into enterprise spreadsheet architecture. Rather than relying on static pivot tables, the workbook constructs a live, formula-driven dashboard sheet connected dynamically to the master record store.

Architecture

Spreadsheet Structure & Transformation Columns

2 Worksheets

Inspection of the raw workbook reveals two sheets. The DATA worksheet houses the 9,515 raw records plus two engineered formula columns:

Column Header Name Underlying Excel Formula Analytical Purpose
Column L RT Score =IFERROR(VALUE(LEFT(F2, FIND("/", F2)-1))/10, "") Extracts numerator before / and normalizes to 0–10 scale
Column M Platform Count =SUM(G2:J2) Sums streaming binary flags to compute multi-platform availability
Audit

Formulas & Computed Values in DASHBOARD Sheet

Audited from Cells A1:R90

Every KPI card and distribution table in the DASHBOARD worksheet is dynamically derived using native Excel formula functions:

Module / Heading Cell Ref Excel Formula Calculated Value
1. Total Records D8 =COUNTA(DATA!C2:C9516) 9,515

1. Latest Movie Year D11 =MAX(DATA!D2:D9516) 2021

1. Missing Age Count D13 =COUNTBLANK(DATA!E2:E9516) 4,177

3. Prime Video Movies D29 =COUNTIF(DATA!I2:I9516, 1) 4,113

Excel Exclusivity Audit Takeaway

Section 9 of the Excel dashboard proves that competition between OTT services is overwhelmingly driven by content exclusivity. Out of 9,515 titles, 9,262 titles (97.34%) are available on exactly one platform. Only 245 titles are shared between 2 services, 7 between 3 services, and a single title (Zapped, 2014) is licensed across all 4.
