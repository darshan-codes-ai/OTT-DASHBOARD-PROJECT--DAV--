Laboratories / Assignment 01

Python & Pandas Exploratory Analysis

Data profiling, duplicate detection, missing-value audit, Rotten Tomatoes score normalization (0–10 scale), and cross-platform content distribution analysis.

Notebook: DAV_Lab_Assignment_1_Movie_Streaming_Analysis.ipynb
Primary Libraries: Pandas, Matplotlib, NumPy
Score Scale: 0–10 (Normalized)

Laboratory 1 establishes the baseline data pipeline for the entire project. Using Python and the Pandas library, the raw dataset is imported, inspected for structural anomalies, cleansed of index artifacts, and analyzed for descriptive properties across the four OTT platforms.

Task 1

Data Profiling & Duplicate Detection

Data Hygiene

The initial CSV file contains 9,515 rows and 11 columns. An inspection using df.info() revealed non-null counts, data types, and an unneeded legacy index column Unnamed: 0.

Python / Pandas (Tasks 1.1 – 1.5) 
# 1. Inspect dimensions
print("Dimensions:", df.shape) # (9515, 11)

# 2. Check for duplicate rows
print("Exact duplicate rows:", df.duplicated().sum()) # 0

# 3. Check for duplicates by Title + Year
movie_duplicates = df.duplicated(subset=["Title", "Year"]).sum()
print("Duplicate movies:", movie_duplicates) # 0

# 4. Remove unnecessary index column
df = df.drop(columns=["Unnamed: 0"])
print("Shape after drop:", df.shape) # (9515, 10)
Key Academic Finding: Deduplication audits confirmed 0 duplicate rows and 0 duplicate (Title + Year) movie pairings. Dropping the legacy index reduced the active feature count from 11 to 10.
Tasks 2 & 3

Missing-Value Audit & Rotten Tomatoes Cleaning

Imputation Audit

Missing value analysis revealed a sharp contrast in completeness. While titles, release years, and streaming availability flags are 100% populated, Age ratings suffer from severe missingness (43.90%).

Column Missing Count Missing %
Age 4,177 43.90%
Rotten Tomatoes 7 0.07%
All other columns (9) 0 0.00%
Rotten Tomatoes String Parsing (Task 3) 
# Strip '/100' string suffix, cast to float, and normalize to 0-10 scale
df["Rotten Tomatoes"] = pd.to_numeric(
    df["Rotten Tomatoes"].astype("string").str.replace("/100", "", regex=False),
    errors="coerce"
) / 10

df["Rotten Tomatoes"] = df["Rotten Tomatoes"].round(1)
print(df[["Title", "Rotten Tomatoes"]].head(3))
